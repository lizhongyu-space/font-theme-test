# Design Lab

An isolated visual design sandbox for the personal website project.

## What this page tests

- Typography samples for Chinese and Latin text, with live font switching
- Four visual presets: Silver Blue, Warm Paper, Graphite, and Blue Note
- Light/dark surface and color token comparisons
- Buttons, status labels, inputs, cards, border radius and hover states
- Gallery and Postcrossing page-pattern previews
- Collapsible sidebar and responsive layouts
- Reduced-motion accessibility preference

## Files

- `index.html` — design lab structure and component examples
- `css/style.css` — design tokens, presets, responsive layout and components
- `js/main.js` — local interactions and preferences

## Important

This repository is a **test lab only**. It is not the production personal website and must not be connected to GitHub Pages. Approved design decisions can later be transferred deliberately to the main repository.

Open `index.html` locally or use a separate preview workflow to inspect the page.
